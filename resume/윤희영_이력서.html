① 외부 벤더 발권·취소 신뢰성 계층 (Transactional Outbox) 2026.06 – 08 기여도 100% · 설계·구현 단독

문제
돈이 걸린 발권·취소를 동기 호출 한 번으로 끝내고 있었음. 취소가 조용히 실패하면 환불은 나가고 좌석은 남았고, 타임아웃 뒤 단순 재시도는 중복 발권을 만들었음.
해결
Outbox 테이블 + 릴레이로 호출을 분리. 예약 단위 멱등키, 조건부 UPDATE로 처리권 선점, 지수 백오프 5회 후 DEAD·Slack 1회 알림. 타임아웃은 자동 재시도 금지·운영자 확인으로 분류하고, 환불 직전에는 취소를 동기로 먼저 보내 실패 시 환불 차단.
성과
Ventrata·Galaxy Connect·Trip.com·Ingresso·Broadway Inbound 5개 벤더에 동일 계층 적용. 취소 실패→환불 차단으로 자금 불일치 원천 차단. 발권·취소 이력은 append-only 감사 테이블로 보존.

② 외부 티켓 벤더 5사 연동 (SOAP·REST) 2025.12 – 2026.08 기여도 약 70% · 외부연동 모듈 69/100 커밋

문제
벤더마다 확정 방식(즉시 과금 vs 폴링)·부분 실패·타임아웃 양상이 달랐고, 60초 넘는 외부 호출 동안 DB 트랜잭션이 열려 락 대기·0건 UPDATE가 발생. 짧은 재시도가 rate limit 연쇄 거부를 유발.
해결
장시간 호출을 트랜잭션 밖 비동기로 분리하고 5분 주기 reconcile로 누락 건 구제. Resilience4j 벤더별 서킷브레이커 + 지수 백오프, 재시도 대상을 5xx·소켓 오류로 한정. 뮤지컬 다건 구매 부분 실패 처리, 결제 직전 재고·가격 재검증.
성과
신규 벤더 4사 연동, 기존 1사 안정화. 자동발권 on/off·결제 시 외부 호출 차단을 어드민 옵션으로 열어 CX팀이 개발자 없이 운영. 실패 유형별 Slack 채널·문구 정리.

③ 외부 상품 가격·옵션 엔진 2025.12 – 진행 중 기여도 약 60% · 가격 프록시 단독 67커밋

문제
벤더 net 가격 + 마진 + 요일/특별기간 할증 계산이 화면·API에 흩어져 장바구니 금액과 결제 금액이 달라지고, 할증 누락·반올림 오차가 반복.
해결
가격 계산을 도메인 서비스 하나로 집약. 지정가/마진가 모드 분리, 특별기간 우선순위(특정일 > 날짜범위) 해석, 장바구니 담을 때 서버 측 검증과 결제 전 가격 변경 감지.
성과
단일 계산 경로로 장바구니–결제 금액 불일치 제거. 가격 산출 근거를 응답에 포함해 운영 문의 대응 시간 단축. 픽패스 업/다운그레이드 정책까지 같은 엔진으로 처리.

④ 파트너센터 구축 + 어드민 권한 체계 2025.11 – 2026.03 기여도 약 65% · 140/211 커밋

문제
현지 파트너·가이드가 배정 주문을 확인할 채널이 없어 CX팀이 수동 전달. 어드민 메뉴 권한이 공통코드에 하드코딩되어 파트너 유형별 분리 불가.
해결

성과
가이드·셔틀·외부 파트너 유형별 권한 분리 운영. 국가별 매출 집계 쿼리 성능 개선.
